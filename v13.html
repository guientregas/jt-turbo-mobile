🤖 WhatsApp automático

Cloud API oficial + webhook

O Turbo pode funcionar de duas formas: abrir o WhatsApp normalmente para você enviar a solicitação, ou usar a Cloud API oficial quando um servidor estiver configurado. A localização recebida pode ser vinculada automaticamente ao pedido pelo telefone.

Fluxo automático
  1. Você toca em Pedir GPS no pedido.
  2. O WhatsApp abre com a mensagem pronta.
  3. O cliente envia a localização atual.
  4. Se a Cloud API estiver configurada, o Turbo recebe e vincula automaticamente pelo telefone.
